Removed dipoles are counted against the largest frame loaded; spmm removes them as ice turns to liquid so that mass is conserved. Axis ratios are the two shorter principal axes over the longest, from the second moments of the dipole positions. Detached dipoles are drawn in orange. Each dipole is drawn as a sphere holding 90% of its cell's volume, so neighbours do not quite touch.

What files can be opened

Frame files as SPMM writes them: one dipole per line, either index x y z type with an optional body column, or x y z type. Type 1 is ice; −1 or 2 is liquid. Header lines are skipped, and an unfinished last line in a file that is still being written is ignored. Select as many frames as the run has produced so far; select them again later to pick up new ones.

The melted fraction comes from the six digits in a name like domain5_f049477.out (49.477%). For other names it is worked out as the share of the largest frame that is no longer ice, so include the earliest frame you have. Connected bodies are always recomputed here from the positions.

A packed .json set written by pack_melt_frames.py can be opened as well; it is a few hundred kilobytes instead of several megabytes per frame, which helps when the run lives on another machine. Files are read in this browser only and are not uploaded.
